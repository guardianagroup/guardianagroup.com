The same task, one day later: the same three services, at the same second

An exact repeat of the 19 September receipt, one day later: Claude Code, the same terminal, the same folder and the same sentence. It took 10.9 seconds — two tenths more than the first time — and the machine looked up the same three services: two from Anthropic and one from Datadog, an application-monitoring company that is not needed to sort five file names. In the five minutes of silence before, with the agent closed, none of the three came up. A measurement that repeats name by name the next day is the only proof that it measures something and not noise.

The task, word for word: “Sort these five invoice file names from oldest to newest.” (original Spanish: «Ordena estos cinco nombres de archivo de factura de más antiguo a más reciente.»)

Window: 15:58:58 UTC → 15:59:09 UTC (10:58:58 → 10:59:09 in Cartagena), 10.9 seconds. Rest before: 300 seconds with the agent closed.

Product: Claude Code (terminal, -p mode), version 2.1.274 (Claude Code). Machine: Microsoft Windows 11 Home 10.0.26200.

Measured by: guardiana 0.2.3, SHA-256 fingerprint 188c7761de0a27a22d3618c91eede3b1875e4c9a31cccbd44ed988c3d6980444.

What the AI answered

The five files, sorted from oldest to newest by the date in the name: papelería La Hoja (21 Nov 2025), Café del Puerto (9 Dec 2025), Electricidad La Chispa (15 Jan 2026), Ferretería El Tornillo (3 Feb 2026) and Transportes Río Magdalena (30 May 2026). Without being asked, it added that it had taken the five files from the folder because they were not in the message, and that it was sorting by the date in the name and not by the file’s modification date. The answer is correct.

The easy reading would be “the one in the cloud watches you and the one at home does not”. That is not what the table shows. What it shows is the price of each thing: the one that looked up nobody was also the one that got the answer wrong, and it is a tiny model, chosen because it was the only one that fit in the free memory of that laptop. The one that got it right had to talk to three services to do it.

The two gaps are not laziness on our part, and that is why they are written down. Codex asks for a paid plan. And with Gemini the owner did sign in with his Google account: the one who closed the door was Google, which no longer serves personal accounts in that program and sends them to another product. It was tried, the date was noted, and it is said here.

Method

A Windows 11 test machine with GUARDIANA installed and the machine’s DNS going through it. First, five minutes of silence with Claude Code closed and the system’s name cache emptied, to learn what the machine asks for on its own. Then the task, typed only once and in non-interactive mode (claude -p), with no connectors, no web search and no permission to open anything outside the folder. The machine’s browser was left open the way its owner keeps it: that is why the background that gets subtracted is from Microsoft and Office. This second time it was launched with nobody in front of the machine, from the development Mac: it took five attempts for the question to get through. When Claude Code has a pipe in front of it, it ignores the text of the argument and reads the question from standard input; until that was found out, it kept answering “it looks like the message arrived empty” (original Spanish: «parece que el mensaje llegó vacío»). The four failed attempts are not published as a measurement because they measured nothing: in them the agent did not do the task.

  • The test files are invented and are published in full inside the raw JSON.
  • Every name the test machine asked GUARDIANA for is counted, from 2 seconds before the task was typed to 5 seconds after the answer. The content of the conversation is neither seen nor stored: GUARDIANA only records names.
  • Names that had already come up in the 300 seconds of rest, with the agent closed, belong to the machine and are not counted against the AI.
  • To repeat it: guardiana export and the two windows of this receipt. If your numbers do not match, write to hola@guardianagroup.com and it is corrected with the date.
