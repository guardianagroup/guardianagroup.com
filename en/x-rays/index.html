How these are made

The machine's DNS points at GUARDIANA, which writes down every name it is asked to resolve, with the time and the device. Each page or application is opened alone, in its own time window, so the names can be attributed. The complete list of names goes out as a CSV next to each x-ray, and the tools are in the program's repository. If you are the maker of something measured here and a figure is wrong, write to hola@guardianagroup.com and it is corrected with the date.
