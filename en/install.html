Step by step, on your system

The summary. Below, each point is explained in detail, with what you will see on screen and why.

Windows 10 and 11

Four steps

  1. Download guardiana-1.0.12-windows-x64-en.msi from the table above.
  2. Check the hash before opening it, in PowerShell:
    (Get-FileHash guardiana-1.0.12-windows-x64-en.msi -Algorithm SHA256).Hash.ToLower()
    and compare it with the one in the public ledger. If they are not identical, delete the file.
  3. Open it. Windows shows this warning. It does not say the program is dangerous: it says Windows does not know it yet.

    If Windows stops it when you open it

    It happens because the program does not carry a publisher certificate yet. It does not say the program is dangerous: it says Windows does not know it yet. Before opening it you can check its hash and its signature. There are two cases; below, a drawing of each Windows screen and where to click:

    You never need to switch off your antivirus, and we will never ask you to.

  4. Once installed, type in PowerShell & "C:\Program Files\Guardiana\guardiana.exe" verify: it repeats the check by itself, on your machine.
Linux with systemd

Four steps

  1. Download guardiana_1.0.12_amd64.deb (or the .tar.gz if you are not on Debian or Ubuntu).
  2. Check the hash and the signature:
    sha256sum guardiana_1.0.12_amd64.deb
    minisign -Vm guardiana_1.0.12_amd64.deb -P <key>
    The public key is already published.
  3. Install:
    sudo apt install ./guardiana_1.0.12_amd64.deb
    On Linux there is no unknown-publisher warning: there is a hash and a signature, which can be checked, unlike a warning.
  4. Check the install with guardiana verify.
macOS 13 or later

Four steps

  1. Download guardiana-1.0.12-macos.app.zip and check the hash:
    shasum -a 256 guardiana-1.0.12-macos.app.zip
  2. Open it. macOS stops it with this warning. Careful: the button selected by default is “Move to Trash”. The one that closes the warning without deleting anything is “OK”.
  3. System Settings › Privacy & Security, and at the very bottom, under “Security”, press “Open Anyway”. Once is enough.
  4. Check the install with /usr/local/guardiana/guardiana verify.

Right-click › Open no longer works on current versions of macOS: we tried it on 19 September 2026 and the same warning appears, with the same two buttons. If someone tells you right-click fixes it, they are repeating something Apple removed.

1 · What Windows will tell you

When you open the installer, Windows shows a blue warning: “Open File – Security Warning”, with “Unknown publisher” and “This file does not have a valid digital signature”. The screenshot below is real, taken on Windows 11 on 15 September 2026 with this same program; only the machine's user name has been covered.

That warning does not say the program is dangerous: it says Windows does not know it yet. It shows for every installer without accumulated reputation, signed or not. With a publisher certificate it can still appear, because since 2024 reputation is earned through downloads, not bought.

We do not hide it and we will not teach you to click past it. We would rather lose users in the first weeks than train anyone to ignore the system's warnings. What we do instead is give you a way to check the file without trusting us.

2 · Three steps to check the file

All three happen before you open anything; the first two need no extra tools, and the third uses minisign.

Step 1 · Take the fingerprint of the file you downloaded

On Windows, in PowerShell:

(Get-FileHash guardiana-1.0.12-windows-x64-en.msi -Algorithm SHA256).Hash.ToLower()

On Linux, in the terminal:

sha256sum guardiana_1.0.12_amd64.deb

Step 2 · Compare it with the public ledger

Every release is written into a public ledger, ledger.jsonl: its fingerprint and the exact point in the code it came from (the “commit”). That entry is also stamped in Rekor, a public timestamp archive, which proves the date. The ledger is published before the download exists. If the two fingerprints are not identical, character by character, the file is not ours: delete it and write to us.

Step 3 · Check the signature

Every file carries its minisign signature next to it. This is the public key every release is signed with. It ships inside the program and has been in the repository, at build/pubkey/minisign.pub, since before any download existed:

RWS+xz+N6DvnuDlJCAIOUEku8PLZ9pP1cUaoQnusfduLWpVIVmPXM16r

Its short id is B8E73BE88D3FC7BE. To check a file:

minisign -Vm guardiana-1.0.12-linux-x86_64.tar.gz -P RWS+xz+N6DvnuDlJCAIOUEku8PLZ9pP1cUaoQnusfduLWpVIVmPXM16r

Once installed, guardiana verify repeats the hash and the signature on your own machine (it checks the public ledger against the ledger.jsonl you download next to the binary), and also tells you whether the service is running, which DNS the system points to and which ports are open.

The hashes for version 1.0.12 are here: in the table above, in the public ledger, where they were written before the download existed, and in Rekor. Each file also carries its signature, made with the key above, which was published before any release existed: that is what makes it checkable. If a hash does not match in all three places, do not open the file.

3 · What the installer does, and what it does not

InstallsThe program in C:\Program Files\Guardiana (Windows), /usr/bin/guardiana (Linux, with the .deb) or /usr/local/bin/guardiana (Linux, with the .tar.gz), and registers the service so it starts with the machine.
Makes GUARDIANA your DNSOn Windows, on a first install GUARDIANA becomes this PC's DNS, over IPv4 and IPv6, so it starts watching from the first minute. It first keeps an exact copy of your setting: if the service stops, the PC gets its previous DNS back, and uninstalling leaves it exactly as it was. It can also be undone from the panel, in “Status”. On Linux the installer does not change it: you do, with the “Point the DNS at Guardiana” button on the panel.
Opens no ports to the networkWith Home Mode off, GUARDIANA listens only on your own machine. Ports towards the Wi-Fi open only if you turn Home Mode on, and guardiana verify lists them for you.
Asks for no accountNo sign-up, no user, no server of ours. The only connections that go out are the licence ones (activating your key and then checking it with the payment gateway: 8 days later and then once per billing period, or every 30 days with the Founder licence), and they are written into your ledger.
Sends nothingZero telemetry. Not while installing, not afterwards.

4 · Linux

On Debian, Ubuntu and derivatives:

sudo apt install ./guardiana_1.0.12_amd64.deb

On any other Linux with systemd, the tarball brings its own installer:

tar -xzf guardiana-1.0.12-linux-x86_64.tar.gz && cd guardiana-1.0.12-linux-x86_64 && sudo ./instalar.sh

On Linux there are no unknown-publisher warnings: there is a hash and a signature, which is more checkable than a warning.

5 · macOS

On a Mac, GUARDIANA downloads as an ordinary application, GUARDIANA.app. The first time you open it, macOS stops it. This is what appears, measured on 19 September 2026 on a Mac running macOS 26.5.2 with an earlier version of this file, downloaded the way you would download it:

Read that dialog before you touch anything: the button selected by default is “Move to Trash”. Press Return without looking and the file goes to the bin. The one that closes the dialog without deleting anything is “OK”.

And there is no shortcut. The old trick —right-click › Open— no longer works on current versions of macOS: we tried it the same day on the same Mac and the same dialog appears, with the same two buttons and no “Open”. If someone tells you right-clicking fixes it, they are repeating something Apple removed.

What does work, once:

  • Try to open it and press “OK” in the dialog.
  • Go to System Settings › Privacy & Security and scroll to the bottom, to the Security section. This is what is there:

Press “Open Anyway” and from then on GUARDIANA opens like any other application. Both screenshots are real, from that same test.

Our test Mac is set to Spanish, so what we read on screen was Apple's Spanish wording; the English above is the same dialog. What we checked, and what matters, is the shape of it: the default button deletes the file, and there is no “Open” button anywhere in that first dialog.

Why that warning appears, and why we work this way

For macOS not to warn, Apple requires the application to be notarised, and notarising requires a paid developer account. We do not have one today. We could have waited until we did and shipped for Mac later; we would rather ship now and tell you exactly what you will see and how to check it yourself.

Same as on Windows: we will not teach you to click past warnings blindly. We give you the file's fingerprint and its signature so you can check that what you are opening is ours, which is the only real reason to open it. On a Mac the check is the same as above, with the command macOS ships:

shasum -a 256 guardiana-1.0.12-macos.app.zip

What the installer does on a Mac

InstallsThe program in /usr/local/guardiana and a start-up service (a LaunchDaemon) that listens only on your own machine, on 127.0.0.1. macOS will ask for your administrator password: the system asks for it, we never see it.
Does not change your DNS on installOn Windows the installer now changes it by itself; on a Mac, not yet. Before touching anything it writes down which DNS each of your networks uses today, so it can put it back exactly as it was. The change happens later, from the panel, with a button.
Opens no ports to the networkOn a Mac, GUARDIANA listens only on the machine itself.
Home Mode: not on Mac yetHome Mode is not in version 1.0 on macOS. Not because it cannot work: GUARDIANA does not manage the macOS firewall and we have not been able to test it there the way we did on Windows and Linux, so we neither vouch for it nor support it on a Mac. On Windows and Linux it is there, tested.

To remove it, open the same GUARDIANA icon and choose to remove: the service stops, it is deleted, and your networks' DNS goes back to what you had before.

6 · Uninstalling

It uninstalls like any other program, and when it does GUARDIANA turns Home Mode off, removes the firewall rule and puts your DNS back exactly as it was, with whatever it pointed to before. What stays is your ledger, which is yours: it is on your disk and you delete it whenever you want.

One small thing also stays, and we say so because we hide nothing: the mark of your 7-day trial: the date it started, the latest clock time the program saw (so moving the date back does not stretch the trial) and, if you activated a licence, a copy of the key; never your name or email. It is kept in HKLM\SOFTWARE\Guardiana (values prueba, visto and licencia) on Windows and in /etc/guardiana/ (prueba-empezada, visto-hasta and licencia) on Linux and the Mac. It stays so that seven days are seven days: if it went away on uninstall, reinstalling would quietly start the count again. An administrator can remove it whenever they want.
