Apontar a casa inteira para a GUARDIANA (roteador)

Uma mudança no roteador e todo aparelho do Wi-Fi passa pela GUARDIANA. A tela exata muda de modelo para modelo; o que vem a seguir é o caminho geral e os nomes usados pelos roteadores mais comuns. Se o seu não estiver aqui, procure «DNS» dentro das configurações de «LAN» ou «DHCP».

Antes de começar

  • No painel da GUARDIANA, página «Modo Casa», ligue e anote o endereço IP do computador (por exemplo 192.168.1.39).
  • Esse endereço precisa ser fixo. Se a GUARDIANA avisar que quem o atribui é o roteador, faça primeiro a reserva de DHCP (mais abaixo).
  • Decida o DNS secundário. Se o computador desligar ou dormir, os celulares apontados só para ele ficam sem DNS. Duas opções, e as duas são honestas:
    • Só a GUARDIANA: tudo passa por ela; se o computador não estiver ligado, os celulares ficam sem internet até ele voltar.
    • A GUARDIANA mais o roteador como secundário: os celulares nunca ficam sem internet; em troca, quando a GUARDIANA não está, essas consultas não são vistas. Alguns celulares usam o secundário de vez em quando mesmo com o primário funcionando: essas consultas também não são vistas.

O caminho geral

  • Abra um navegador e vá ao endereço do roteador: normalmente 192.168.1.1 (às vezes 192.168.0.1). O usuário e a senha estão na etiqueta do roteador.
  • Procure LAN, Rede local ou DHCP.
  • Você vai encontrar «Servidor DNS», «DNS primário / secundário» ou «Servidores DNS do DHCP».
  • Primário: o endereço do computador. Secundário: vazio, ou o endereço do próprio roteador.
  • Salve. Alguns roteadores reiniciam.
  • Em cada celular, desligue e ligue o Wi-Fi para ele pegar o DNS novo.
  • Confira a partir de um celular: http://comprobar.guardiana.hogar.

Reserva de DHCP (um endereço fixo para o computador)

Na mesma seção LAN/DHCP costuma haver «Reserva de endereços», «DHCP estático» ou «Atribuição fixa». Você adiciona o endereço MAC do computador (a GUARDIANA mostra em «Meu aparelho»; no Windows, ipconfig /all, «Endereço físico») junto com o endereço que quer manter. Salve e reinicie o Wi-Fi do computador.

Se você não pode ou não quer entrar no roteador: endereço fixo no próprio computador

A reserva de DHCP pode ser trocada por fixar o endereço no computador guardião. Não é preciso tocar no roteador. Use o mesmo endereço que ele já tem, para não colidir com ninguém.

Windows, numa janela do PowerShell como administrador (troque Ethernet pelo nome da sua conexão e os endereços pelos seus; 192.168.1.1 costuma ser o roteador):

netsh interface ipv4 set address name="Ethernet" static 192.168.1.78 255.255.255.0 192.168.1.1

netsh interface ipv4 set dnsservers name="Ethernet" static 192.168.1.1 primary

Para desfazer: netsh interface ipv4 set address name="Ethernet" dhcp e netsh interface ipv4 set dnsservers name="Ethernet" dhcp.

Linux com NetworkManager (Ubuntu desktop, Mint, Fedora): Configurações › Rede › a engrenagem da sua conexão › IPv4 › «Manual» › endereço, máscara 255.255.255.0, gateway o roteador.

Com endereço fixo, o que falta é apontar os celulares para ele (os guias do iPhone e do Android). O DNS no roteador continua sendo o mais confortável para a casa inteira, mas não é obrigatório.

Se o roteador não deixar mudar o DNS

Isso acontece com alguns roteadores de operadora. Duas saídas:

  • Configurar o DNS em cada celular (guia do iPhone, guia do Android).
  • Desligar o DHCP do roteador e usar o do computador: a GUARDIANA não faz isso na 1.0, e está anotado como um limite.

Desfazer

Volte à mesma seção e deixe o DNS em «automático», ou no valor que ele tinha. A GUARDIANA nunca mexe no seu roteador: o que você mudou, você desfaz.
