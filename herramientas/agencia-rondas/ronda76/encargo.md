PROYECTO: DISEÑO DE UNA APLICACIÓN DE MENSAJERÍA DE NIVEL MUNDIAL

Actúa como un equipo de élite formado por:

* Director creativo de Apple.
* Diseñadores de producto de WhatsApp, Signal, Telegram y iMessage.
* Especialistas en UX/UI para aplicaciones de comunicación.
* Expertos en diseño mobile-first.
* Ingenieros especializados en interfaces de mensajería.

Tu misión es diseñar la interfaz completa de GUARDIANA COMUNICACIONES, una aplicación de mensajería moderna, elegante, intuitiva y profesional.

1. REFERENCIA DE CALIDAD

Quiero alcanzar el mismo nivel de facilidad de uso, familiaridad, velocidad visual y madurez de producto que WhatsApp.

Puedes estudiar los patrones de interacción de WhatsApp, Signal, Telegram e iMessage como referencias de usabilidad.

IMPORTANTE:

* No copies WhatsApp.
* No reproduzcas exactamente su distribución, iconos, colores, componentes ni identidad visual.
* No quiero un clon.
* Quiero un producto original que alcance ese nivel de calidad.
* Cada decisión debe tener una razón de UX.

El resultado debe sentirse como una aplicación que podría competir internacionalmente con las mejores aplicaciones de mensajería.

2. IDENTIDAD VISUAL

La estética debe transmitir:

* Privacidad.
* Confianza.
* Seguridad.
* Elegancia.
* Tecnología.
* Profesionalidad.
* Sencillez.

Evita:

* Colores infantiles.
* Gradientes exagerados.
* Botones gigantes innecesarios.
* Exceso de tarjetas.
* Sombras artificiales.
* Iconografía inconsistente.
* Interfaces recargadas.
* Apariencia de plantilla genérica de SaaS.

Utiliza una estética oscura, sobria y contemporánea.

Referencia cromática:

* Fondo principal: #06080C
* Superficies: #0C1118
* Texto principal: #E8ECF1
* Texto secundario: #A9B3BE
* Acento: #9CC3E4
* Alertas: #E07A6C

Tipografía moderna, excelente legibilidad y jerarquía muy cuidada.

Botones rectangulares, esquinas moderadas y componentes coherentes.

3. DISEÑA TODA LA EXPERIENCIA

No te limites a diseñar una pantalla bonita.

Quiero una aplicación completa con:

1. Pantalla principal de conversaciones.
2. Buscador de conversaciones y contactos.
3. Nueva conversación.
4. Invitaciones para conectar con otras personas.
5. Conversación individual.
6. Conversaciones grupales.
7. Mensajes enviados, recibidos y pendientes.
8. Respuestas a mensajes.
9. Reacciones.
10. Notas de voz.
11. Reproducción de notas de voz.
12. Envío de archivos.
13. Vista previa de fotografías y documentos.
14. Descargas y transferencias.
15. Llamadas de voz.
16. Incorporación de participantes a una llamada.
17. Historial de llamadas.
18. Perfil del contacto.
19. Información de seguridad de la conversación.
20. Gestión de dispositivos.
21. Ajustes y preferencias.
22. Notificaciones.
23. Estados vacíos, errores y estados de conexión.

No inventes funciones que no estén contempladas en el producto real. Si propones funcionalidades nuevas, identifícalas como propuestas.

4. EXPERIENCIA MÓVIL

El móvil es prioritario.

Diseña pensando en iPhone y Android, con diferentes tamaños de pantalla.

La interfaz debe:

* Aprovechar cada centímetro de pantalla.
* Tener navegación sencilla.
* Mantener los controles importantes al alcance del pulgar.
* Evitar desplazamientos innecesarios.
* Mostrar claramente las acciones disponibles.
* Facilitar escribir, responder, enviar archivos y llamar.
* No sacrificar funcionalidad por estética.

Quiero una experiencia que se entienda sin instrucciones.

5. EXPERIENCIA DE ESCRITORIO

Diseña también la versión para ordenador.

Utiliza una distribución de tres columnas cuando tenga sentido:

* Izquierda: conversaciones y navegación.
* Centro: conversación activa.
* Derecha: información de la conversación, participantes y seguridad.

No fuerces las tres columnas en pantallas pequeñas.

6. DETALLES QUE DIFERENCIAN UN PRODUCTO EXCELENTE

Presta especial atención a:

* Espaciado.
* Alineación.
* Tamaños de botones.
* Estados activos e inactivos.
* Animaciones discretas.
* Jerarquía visual.
* Lectura rápida de mensajes.
* Identificación de participantes.
* Accesibilidad.
* Comportamiento del teclado.
* Estados de carga.
* Errores y recuperación.
* Consistencia entre móvil y escritorio.

Cada pantalla debe parecer terminada y lista para un producto comercial.

7. MÉTODO DE TRABAJO

Trabaja en este orden:

FASE 1. Investiga los mejores patrones de interacción de las aplicaciones de mensajería actuales.

FASE 2. Define una identidad visual propia para GUARDIANA.

FASE 3. Diseña la arquitectura de navegación completa.

FASE 4. Diseña las pantallas principales y secundarias.

FASE 5. Construye los componentes reutilizables.

FASE 6. Implementa un prototipo navegable y funcional.

FASE 7. Comprueba la experiencia en diferentes tamaños de pantalla.

FASE 8. Realiza una auditoría visual y de usabilidad. Corrige inconsistencias.

8. EXIGENCIA FINAL

No quiero un diseño que simplemente parezca moderno.

Quiero un producto que transmita que detrás hay un equipo de diseño de primer nivel.

Compara mentalmente cada pantalla con los estándares de Apple, WhatsApp, Signal y Telegram.

Si una pantalla está recargada, simplifícala.
Si una acción no se entiende, rediseñala.
Si un botón no aporta valor, elimínalo.
Si hay demasiados pasos para realizar una acción, redúcelos.

No sacrifiques claridad por originalidad.

El objetivo: crear una aplicación de mensajería reconocible, elegante, extremadamente fácil de usar y con identidad GUARDIANA propia.

Antes de modificar el código existente, analiza la arquitectura, identifica los componentes reutilizables y presenta el plan de implementación. No rompas las funcionalidades que ya funcionan.
