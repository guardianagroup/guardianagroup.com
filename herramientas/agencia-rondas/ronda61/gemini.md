- **A) Posible:** índice propio de toda la web, inviable para un equipo pequeño (Mojeek, Brave/Tailcat, Qwant+Ecosia con EUSP; Marginalia y Stract solo en nichos). Metabuscador: **la API de Bing se apagó en agosto de 2025**; **Brave Search API** viva (índice propio; gratis con atribución y de pago); Mojeek API viva (menos cobertura en español); Google Programmable Search, limitada. **Recomienda el híbrido**: índice propio de las webs más visitadas de cada país (bancos, impuestos, periódicos, tiendas) + Brave Search API para el resto, siempre desde nuestro servidor (nunca con la IP de la persona).
- **B) Las 100 por país:** CrUX (Chrome UX Report) por país, por bloques de popularidad (no el orden exacto); Cloudflare Radar (dice CC BY 4.0: **falso, es CC BY-NC 4.0**, ver notas); Tranco, sin licencia comercial directa; Similarweb y Semrush, descartadas (prohíben extraer y redistribuir). Empezar con 50 países (~3.200 dominios únicos), actualizar cada mes y comprobar cada dominio con el motor de ZERO (HTTPS, que no esté aparcado, su Radiografía).
- **C) Lo de GUARDIANA:** el **semáforo de privacidad** en cada resultado (empresas, países, subastas) antes de entrar; se abre en ZERO; sin registros, sin IP, sin cookies, sin perfil; **alerta de suplantación** si un resultado se parece a la web oficial verificada sin serlo; listas de malware con licencia comercial: URLhaus y ThreatFox (abuse.ch, CC0), malware-filter; OpenPhish y PhishTank no sirven gratis para uso comercial.
- **D) «100 % limpio y 0 virus»:** no existe; prometerlo nos expone ante la SIC. Lo verdadero: el código de la web corre en un contenedor de GUARDIANA y no toca el equipo. No evita que alguien escriba su clave en una página falsa ni lo que se baje y abra fuera de ZERO. Frase: «Las webs no se abren en tu equipo, sino en un servidor blindado de GUARDIANA: a tu pantalla solo llega la imagen limpia y ves quién intenta rastrearte antes de entrar…».
- **E) Tecnología:** rastreador Node.js ligero que respeta robots.txt (RFC 9309) con un `User-Agent` propio; **Meilisearch** para empezar (MIT, tolera erratas, muchos idiomas), Tantivy/Quickwit o OpenSearch/Vespa más adelante; orden = relevancia (BM25) + país + bonificación por privacidad. Coste: servidor 8 vCPU/32 GB (45–70 $/mes) + Brave API (150–300 $/mes) ≈ 200–370 $/mes.
- **F) Leyes:** robots.txt y `nosnippet`/`max-snippet`; Directiva 2019/790, art. 15 (editores de prensa: solo extractos muy breves); derecho al olvido (Google Spain, C-131/12) con formulario; DSA: lo duro solo para buscadores de más de 45 millones de usuarios en la UE; Ley 1581 y RGPD: sin IP ni historial no hay base de datos de usuarios.
